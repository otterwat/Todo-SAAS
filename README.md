# TodoSAAS
main file is the main.py file. It contains the FastAPI application and the endpoints for the TODO application. The application uses SQLAlchemy for database interactions and Pydantic for data validation.
github repo will not be working files, just for storage/backing up since the project is static and currently need sa server to run.
REQUIREMENTS TO RUN:
uvicorn
fastapi
sqlalchemy

download these packages in terminal to build the project yourself.
or visit https://todo-saas-px83.onrender.com to see the global project! (users will be coming soon, global list will still be available)
